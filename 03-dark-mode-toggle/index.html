§ 03 — foundations

dark-mode-toggle

This page defaults to your system theme via prefers-color-scheme. Use the toggle to override. Zero JavaScript — the override works through :has() and radio inputs.

Preview content

This card uses the same CSS variables as the rest of the page. Toggle above and watch every color update in one frame — that's the point of driving everything through custom properties.

The whole theme is three CSS custom properties on :root. Media queries set the defaults; html:has(#theme-light:checked) and html:has(#theme-dark:checked) override them when the user picks a mode. The radio input for "auto" is just the absence of the other two.
