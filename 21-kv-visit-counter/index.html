kv-visit-counter

Every load of this page hits /api/count, which reads the current value from Workers KV, increments it, writes it back, and returns the new total.

Total visits
—

KV is eventually consistent across regions — if you refresh quickly from different continents, you might briefly see the old value. For a visit counter, that's fine.

The real gotcha with this pattern: writing to KV on every request doesn't scale. KV is optimized for hot reads, not hot writes. See the README for how to do it right at traffic.
