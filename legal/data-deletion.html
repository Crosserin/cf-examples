Data Deletion

Last updated: April 22, 2026

This page explains how the operator of our social media integration application (registered with Meta Platforms as crosserinlabs-postiz) can request that data the app has received or retained be deleted.

Context. This app is used solely by Erin Cross, as operator of X = Consulting, to manage social media accounts and Pages the operator personally owns. Nobody else has data in the app. This page exists because Meta Platforms requires every app to publish a data deletion URL, regardless of user count.

What data the app holds

The application stores the following types of data:

  • OAuth access tokens issued by platforms (Meta, LinkedIn, Bluesky, Mastodon, etc.)
  • A database of drafted and scheduled posts, authored by the operator
  • Media files (images, video) attached to scheduled posts
  • Metadata about past publishing activity (what was posted, when, where)
  • Basic profile data returned by the platforms during OAuth (name, handle, email)

How to request deletion

Option 1 — Revoke access at the platform level (immediate)

The fastest way to make this app forget about you is to revoke the app's access token directly at the platform. This also invalidates any stored tokens we hold.

  • Facebook / Instagram: Settings → Business Integrations → find crosserinlabs-postiz → Remove
  • LinkedIn: Settings → Data privacy → Permitted services → find our app → Remove
  • Bluesky: Settings → App passwords → revoke the Postiz password
  • Mastodon: Preferences → Authorized applications → revoke

Option 2 — Email request (full data wipe)

To request that all data associated with a specific account (platform handle or email address) be purged from the application's database, send an email to erin@xconsultingwork.com with the subject line "Data deletion request".

In the email, include:

  • The platform the data relates to (Facebook, Instagram, LinkedIn, etc.)
  • The account handle, email, or other identifier associated with the data
  • A short confirmation that you are the authorized owner of that account

Confirmation timeline

  • We respond to deletion requests within 7 business days.
  • Once we confirm the request, all associated data is removed from the application's database and any active backups within 30 days.
  • We will reply with a confirmation code so you can reference the request if needed.

Confirmation code format

If Meta Platforms or another service needs a confirmation code format for their records, our codes follow the pattern DEL-YYYYMMDD-XXXX, where XXXX is a short random string. For example: DEL-20260422-A3F7.

What can't be deleted

A few items are outside the app's control:

  • Posts that have already been published to third-party platforms live on those platforms according to the platform's own retention rules. We can delete the app's record of them, but we cannot remove them from, e.g., Facebook's servers. Use each platform's own delete-post flow for that.
  • Platform-side analytics data that Meta, LinkedIn, etc. collected during normal operation is subject to those platforms' own data policies and deletion flows.
