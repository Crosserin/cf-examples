Preamble

A worked tour of the Cloudflare edge platform, from a single static HTML file to a Workers AI chat endpoint backed by D1. Each example is self-contained, readable in one sitting, and deployed live.

I run IT and managed services by day — Intune packaging, Proxmox homelabs, the occasional "why is Samba broken at 2am" — and consult on the side through xconsultingwork.com. This repo is the public-facing version of how I think about building things: small, specific, and shippable.

Numbered, tagged, and grouped by what they demonstrate. Click any card to open the live example; each one links back to its source.
