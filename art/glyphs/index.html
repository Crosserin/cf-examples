Letters breathe.

Type that reacts to where it sits in your viewport. Each letter tracks its own vertical position and transforms in response — stretching on approach, collapsing on departure. Scroll slowly.

Every letter is a single <span>. On every scroll event, JavaScript computes each glyph's distance from the viewport center, normalizes it to 0–1, and writes it to a CSS custom property --p. All the motion is then just transform and color doing arithmetic on that one number.

No libraries. No animation frames. ~40 lines of vanilla JS.
