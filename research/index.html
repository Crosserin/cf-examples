Real consulting problems don't respect domain boundaries. A question about solar installation becomes a question about NEC code, which becomes a question about temperature coefficients, which becomes a question about conductor sizing.

This path is the interdisciplinary grab-bag — tools built from actual client work, stripped of specifics, made public.

"Only an interdisciplinary approach will correctly deal with reality." — attributed to no one in particular, found on every consulting website, still true anyway

Three works. Each solves a specific problem you may never have — until you do.
